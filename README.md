# AvatarKit iOS SDK

Real-time virtual avatar rendering SDK for iOS — audio-driven animation and high-quality 3D rendering with Metal.

## Installation

### Swift Package Manager

```swift
dependencies: [
    .package(url: "https://github.com/spatius-ai/avatarkit-ios-release.git", from: "1.0.0")
]
```

### XCFramework (Binary)

Download the latest `AvatarKit.xcframework` from [Releases](https://github.com/spatius-ai/avatarkit-ios-release/releases), drag it into your Xcode project, and set it to **Embed & Sign**.

## Requirements

- iOS 16.0+
- Metal, AVFoundation
- arm64
